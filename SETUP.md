# Aplicar o perfil — Midnight Orbit

Banner editável: [Figma](https://www.figma.com/design/yh56LKJngtXd768xZ4LGmY?node-id=2-2).

## Instalação

1. Extraia o ZIP.
2. Copie README.md e assets/github-banner.svg para o repositório JoaoVictorAAbreu-Dev/JoaoVictorAAbreu-Dev, preservando os demais arquivos.
3. Faça o commit na branch padrão. Não é necessário instalar workflow nem fornecer token para esta versão.

Se você instalou a configuração da versão anterior, o workflow profile-statistics.yml e os SVGs github-stats.svg e top-languages.svg não são mais utilizados por este README. Nenhum arquivo remoto foi removido.

## Estatísticas: projeto original solicitado

As imagens usam diretamente https://github-readme-stats.vercel.app/api e /api/top-langs/, documentados no [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats).

Fundo transparente, sem bordas, destaques em anil, ranking oculto e até seis linguagens. Não foi usado o fork GitHub Stats Extended nem sua Action.

O repositório original informa que não é mais mantido e que a instância pública funciona em regime de melhor esforço, sujeita a limites de requisições e indisponibilidade. Os endpoints foram configurados conforme a documentação; não houve confirmação de renderização dos dados reais nesta entrega. O README não contém números inventados.
